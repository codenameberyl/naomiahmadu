A · Editorial

A warm, magazine-style portfolio: linen paper, ink type and one terracotta accent. Results are set like headline type.

Type

Fraunces (variable serif, opsz 9–144, real italic) for display, metrics and the italic translated. Instrument Sans for body and UI. Metrics use Fraunces Light at the large optical size with tabular lining numerals; the % sign is smaller and set in the accent colour.

Scale (fluid clamp): H1 2.6→5.75rem · Metric 3→5.25rem · H2 1.9→3.25rem · H3 1.6→2.4rem · Body 1→1.125rem · Label .8rem / +.14em caps.

Tokens

Radius 4 / 8 / 12px, pill buttons. No shadows; structure comes from 1px hairline rules. Spacing on a 4px base: 4, 8, 12, 16, 24, 32, 48, 64, 96, 112.

Components

Hero: eyebrow with a short accent rule, very large serif H1 with translated in light italic terracotta, muted intro, pill CTAs. Metrics: a ruled ledger strip with vertical dividers (2×2 on mobile). Work card: an editorial spread: image left, italic "Role 02", serif title, outlined chips and a text link. Nav: translucent sticky bar, underline in the accent marks the current page, theme icon and pill "Get in touch" always visible; on mobile, a "Menu" button opens a full-screen sheet with large serif links.

B · Signal

A confident, modern grotesk with one bright marigold highlight that frames each result like a scoreboard, softened by rounded cards and a serif italic accent.

Type

Bricolage Grotesque (variable, opsz 12–96) for display and metrics at ExtraBold. Instrument Serif Italic for the single word translated (and pull quotes), with a marigold highlighter behind it. Manrope for body and UI.

Scale (fluid clamp): H1 2.6→5.75rem, tight −0.035em tracking · Metric 3→5.25rem · H2 1.9→3.25rem · H3 1.6→2.4rem · Body 1→1.125rem · Label .8rem / +.14em caps.

Tokens

Radius 8 / 16 / 24px, pill buttons and chips. Soft two-layer card shadow in light mode, none in dark (surfaces step up in tone instead). Same 4px spacing base.

Components

Hero: eyebrow with a glowing marigold dot, heavy grotesk H1, serif-italic translated on a highlighter stroke, teal pill primary CTA. Metrics: four rounded tiles alternating marigold and white (checkerboard on mobile), with huge ExtraBold numerals. Work card: a single rounded white card, image left, teal tinted chips. Nav: the current page sits in a soft pill; the rest matches A.
